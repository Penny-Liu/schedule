# 放射師預假優先休順序

在「請假管理」找到放射師的單日預假，主管或系統管理員可依抽籤結果填寫第 1～999 順位，按「儲存順位」保存，也可清除。一般同仁可查看自己預假的已填順位。

排班人員視角待審預假標記顯示「預1」「預2」，崗位視角的預假小標記也附上順位；未設定仍顯示「預」。此註記不自動核准、不更改排班、不改變自動排班規則。

同一天的有效預假不可有相同順位；若要互換兩人的順位，先清除其中一人的順位再依序重設。不同日期可各自從 1 開始；已駁回的順位保留為歷史註記，不占用有效順位。

## 啟用

需先套用 `supabase/migrations/20261122115053_add_pre_leave_priority.sql`，再部署新版 App。主管需使用已綁定的 Supabase 安全登入；資料庫 trigger 也會驗證實際登入者角色，前端隱藏按鈕不是唯一限制。

本次發佈前已唯讀核對正式資料庫：順位欄位、trigger 與唯一索引已存在且與本檔規則相符，因此不重複套用 SQL；未修改正式請假資料。沒有新增或放寬既有讀取政策。
