# 放射師今日視角後台同步

放射師主管與系統管理員可在今日視角日期工具列按「後台同步」。預設以目前畫面選取日為開始與結束，選擇每日統計（醫令數、客戶量、MR 排程）及影像醫師工作量分類。可以修改日期，也可快速選擇「選取日＋未來30天」（含選取日共31天）。不預選健管、行政或其他部門的同步任務。

沿用統計頁的同步後端，兩處共用 services/backendSync.ts。開發版呼叫本機 /api/sync-stats；正式版沿用 sync-stats.yml workflow_dispatch 與既有 GitHub PAT 設定，沒有新增前端伺服器端金鑰。

雲端回應僅表示已送出，不代表同步完成；視窗提供 GitHub 執行狀態連結與「讀取最新資料」。本機後端同步完成會自動讀取目前統計與工作量。開發沙盒阻擋正式同步。

驗證：424 項測試、TypeScript 與 Vite 建置通過。測試使用模擬 HTTP，不觸發正式同步；實際瀏覽器點選與後端同步驗收尚待完成。本批與健管統計／週期功能一併發佈。

本分支亦保留前面已完成的視角切換靠左、LINE 區塊6／7對調，供後續一起部署。
