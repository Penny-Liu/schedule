## 第一批變更

- Store 只合併尚未完成的帳號初始化，不新增跨登入的長期快取。
- 完成後 force=true 仍重新載入，保留登入前刷新帳號與安全登入綁定判斷。
- React effect 卸載時移除 Capacitor 前景事件；若註冊較晚完成也立即移除。
- 已卸載的啟動 effect 不再更新 React 狀態。
- 不變更資料庫、排班、請假、點值、S/T 公式及匯出內容。

驗證：400 項測試、TypeScript 檢查與 Vite 建置。實際桌機／手機操作效能驗收仍待完成。
