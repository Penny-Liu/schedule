# 放射師兼任崗位

- 人員視角的「＋任務」可選兼 CT、US1～US4、MR3T、MR1.5T；保留既有兼 BMD/DX。
- 崗位視角的「＋」也可選已在另一檢查崗位且具備目標獨立資格的人員，選單會以「兼」標註兼任人員。此操作加入兼任，不搬動主崗。
- 移除兼任崗位只解除兼任；移動主崗到休假、行政等非檢查崗位會清掉檢查兼任。
- 兼任不新增當日排班紀錄；全科／院區負載從原始排班按日期、人員去重，只計一次原本的人力供給。崗位清單的重複顯示不增加供給。
- 保留既有編輯權限、場控限制、遠班兼骨密和大直支援規則。學習班不能透過新增兼任當作獨立操作。
- 沿用 specialRoles 的字串陣列，不需資料庫 migration。

兼任崗位的人員標記統一僅顯示「兼」，不顯示主崗位名稱或重複的兼任任務文字。

主崗位顯示完整兼任位置（如「兼CT」「兼US4」）；兼任位置仍僅顯示「兼」。
