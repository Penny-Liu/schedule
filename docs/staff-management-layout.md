# 人員管理分類

桌面版左側為可管理人員名單，右側為編輯表單；窄螢幕上下排列。表單獨立捲動，儲存與取消維持固定可見。

## 右側四區

- 基本資料：姓名、簡稱、登入帳號、放射師出生年月日、代表顏色。
- 工作身分：放射師／健管勾選、管理院區、角色、組別與異動；專業技能與學習資格收合。
- 操作權限：說明角色仍套用既有預設，細項勾選收合；顯示已選數量。
- 帳號狀態：唯讀安全登入綁定狀態、在職、到離職日期、留職停薪、管理員既有沙盒開關。

## 左側篩選

搜尋姓名、帳號或簡稱，搭配部門、健管管理院區、角色；可以清除篩選，無結果時有提示。沿用原本主管的部門／院區限制及離職名單規則，不因篩選擴大可管理名單。

## 本次範圍

只重整既有欄位與顯示；沒有新增資料庫欄位、權限範本或個人／公用帳號分類值。不依姓名猜測帳號類型；安全登入綁定不由表單儲存自動建立。

版面靜態渲染與程式檢查可執行；本次瀏覽器預覽服務無法連線，實際桌面與手機操作驗收仍待完成。本批併同預假順位功能發佈。

## 快速複製權限

「操作權限」區可選擇參考人員，按「預覽權限」查看新增、移除及套用清單，再按「確認套用到表單」。只變更表單的功能權限，最後按儲存才走既有帳號儲存流程。

- 不帶入角色、院區、姓名、帳密、安全登入綁定或工作資格。
- 系統管理員可參考所有在職帳號；主管只可參考既有部門／院區範圍的人員，且不複製自己沒有的權限。
- 未知的功能權限與來源的開發沙盒旗標不複製；目標原有非功能旗標保留。
- 不可參考自己正在編輯的帳號；參考資料在預覽後改變時要求重新預覽。
- 無需 SQL；目前本批併同預假順位功能發佈。
